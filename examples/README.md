# Reference Image Guide / 参考效果图指南

Reference images are optional. 3–6 good examples are usually enough.  
参考效果图是可选项，通常 3–6 张就够了。

## Privacy / 隐私

For a public GitHub repository, do not upload:
公开 GitHub 仓库中不要上传：

- private CR2 originals / 私人 CR2 原图
- personal photos you do not want public / 不想公开的私人照片
- someone else's face without permission / 未经授权的他人人像
- files containing sensitive metadata / 含敏感元数据的文件

You may keep reference images private by uploading them only inside your ChatGPT Project.  
参考效果图完全可以只上传到自己的 ChatGPT Project，不放到 GitHub。

## Recommended set / 推荐参考图组合

1. Clean portrait / Clean 风格
2. Editorial portrait A / Editorial A
3. Editorial portrait B / Editorial B
4. Horizontal image / 横图
5. Text example / 有文字
6. No-text example / 无文字

## Good reference characteristics / 好参考图的特征

- one dominant portrait / 一个明确主体
- controlled red / black / off-white palette / 黑红白受控配色
- sparse portrait fragments / 少量人物碎片
- deliberate negative space / 有意识留白
- torn paper / photocopy / graffiti texture / 撕纸、复印、涂鸦质感
- clear hierarchy / 明确视觉层级

Avoid references whose main idea is simply duplicating the person's face many times.  
避免选择“重复贴很多人物脸”作为主要视觉手段的参考图。

## Optional annotation / 可选说明

```text
Reference 01 / 参考图 01
Preset / 风格：Editorial

Important / 重点：
- orientation preserved / 横竖方向保留
- one portrait inset only / 只有一个人物局部
- red concentrated on right side / 红色主要集中在右侧
- torn paper fills empty area / 撕纸主要填补空白
- no invented face / 没有 AI 新生成人脸
```
