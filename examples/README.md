# Reference Image Guide

Reference images are optional, but 3–6 good examples can make the Project's visual target easier to understand.

## Do not put private originals here

For a public GitHub repository, do not upload:
- private CR2 files
- unretouched personal originals you do not want public
- someone else's face without permission
- files containing sensitive metadata you do not want to publish

You can keep Project reference images private by uploading them only inside your ChatGPT Project.

## Recommended reference set

A useful six-image set would be:

1. **Clean portrait**
   - main portrait clearly dominant
   - minimal collage

2. **Editorial portrait A**
   - one source-photo inset
   - torn paper + red paint

3. **Editorial portrait B**
   - no portrait inset
   - strong typography or negative space

4. **Horizontal image**
   - proves landscape orientation is preserved

5. **Text example**
   - exact custom phrase
   - text does not cover the face

6. **No-text example**
   - demonstrates that visual complexity can come from texture rather than fake copy

## What makes a good reference

A strong reference should demonstrate:
- one dominant portrait
- controlled red / black / off-white palette
- sparse source-photo fragments
- deliberate negative space
- tactile paper / photocopy / graffiti texture
- readable hierarchy

Avoid reference images whose main visual idea is simply duplicating the person's face many times.

## Optional annotation

If you publish references later, add a short note for each image:

```text
Reference 01
Preset: Editorial
Important:
- orientation preserved
- one portrait inset only
- red concentrated on right side
- torn paper fills empty area
- no invented face
```

The explanation is often as useful as the image itself.
