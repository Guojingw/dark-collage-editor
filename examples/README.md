# Reference Image Guide / 参考效果图指南

Reference images are optional. 3–6 strong examples are usually enough.

The key rule in v3 is:

**STYLE_REFERENCE images teach design language only. They are never portrait donors.**

## Privacy / 隐私

For a public GitHub repository, do not upload:

- private CR2 originals
- personal photos you do not want public
- someone else's face without permission
- files containing sensitive metadata

Reference images can stay private inside your own ChatGPT Project.

## Recommended reference set / 推荐组合

A useful 3–6 image set may include:

1. strong Editorial portrait
2. another Editorial page with different macro geometry
3. close-up / Tight Crop example
4. horizontal / Graphic Negative Space example
5. typography-heavy example
6. no-text example

You do not need every category.

## What the editor should learn / 应该学习什么

Learn only:

- black / oxblood / dirty-white balance
- collage density
- tear scale and direction
- xerox / halftone intensity
- typography scale
- red gesture behavior
- paper / print material
- negative-space amount
- portrait-to-graphics relationship
- page hierarchy

## What the editor must never borrow / 绝对不能借什么

Never borrow from a STYLE_REFERENCE:

- face
- eye
- mouth
- hand
- hairstyle
- clothing
- jewelry
- body
- pose
- portrait fragment

When the reference contains a person, that person's identity is irrelevant to the edit.

## Good reference characteristics / 好参考图

- one dominant portrait
- obvious macro structure
- controlled black / red / off-white palette
- sparse portrait fragments
- deliberate negative space
- torn-paper / photocopy / zine material
- clear visual hierarchy
- strong interior composition, not just a border

Avoid references whose only idea is:
- repeated faces
- sticker spam
- random readable English
- all-over texture with no macro design
- four-sided torn borders

## How to label references in a chat / 聊天中怎么说

Recommended:

> Images 1–3 are style references only. Image 4 is the target. Use the references for visual language only; do not borrow people, faces, eyes, hands, clothes, or portrait fragments.

中文：

> 1–3 是风格参考图，第 4 张是 TARGET。参考图只学习视觉语言，绝对不要借人物、脸、眼睛、手、衣服或人像碎片。
