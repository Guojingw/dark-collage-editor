# Example requests

These should work without users learning prompt syntax.

## Single image

“把这张照片修成暗黑拼贴涂鸦风，不要文字。”

“Make this photo dark editorial collage style. Clean, no text.”

## Custom text

“这张用 Editorial，文字写 STAY IN THE NOISE。”

“Use chaotic style and put NOTHING FEELS REAL in the background.”

## Batch

“把这 9 张做成一组，风格统一但每张版式不同。Editorial。不要乱贴很多人像。”

“Edit these 12 portraits as one consistent dark collage series. Use the text I give for each file.”

## Strict portrait preservation

“脸、动作、衣服都不要改。拼贴里的眼睛和脸只能从我上传的照片里截。”
