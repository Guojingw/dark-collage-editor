# Chaotic preset

Use when the user wants a more aggressive poster / zine result.

- Main portrait: 60–80% visual attention
- Portrait fragments: 1–3 maximum
- Torn paper: high
- Graffiti: high
- Red accents: high
- Typography: medium to high
- Grain / scratches: high
- Negative space: low to medium
- Composition: intentionally asymmetrical and layered

Important: add chaos using graphics and texture, not by adding many repeated faces.
