# Final Quality Checklist

Before finalizing each image, verify:

- [ ] Same person / identity as source photo
- [ ] Main pose preserved
- [ ] Original horizontal/vertical orientation preserved
- [ ] Main portrait is still the visual focus
- [ ] No invented extra faces
- [ ] 0–3 portrait fragments maximum, depending on preset
- [ ] Any portrait fragments are reused from user source photos
- [ ] No unexplained change to hairstyle, clothes, jewelry, or hands
- [ ] Red/black/white visual language is coherent
- [ ] Collage density comes mainly from non-portrait elements
- [ ] Text exactly matches the user's wording
- [ ] No fake readable copy when user requested no text
- [ ] Text does not accidentally cover defining facial features
- [ ] Batch output does not repeat the exact same composition
- [ ] Subject remains readable against background
- [ ] Result feels designed, not merely cluttered
