# Style Guide

## Visual identity

Dark editorial collage with punk / goth / emo / zine influence.

### Palette
- Black / charcoal: dominant
- Deep red / oxblood: accent
- Off-white / dirty white: contrast
- Skin tone: preserve where it helps identity and photographic realism

### Texture hierarchy
Use 2–5 of these per image, not all of them at maximum strength:
- torn paper
- photocopy grain
- halftone
- paint stroke
- red splatter
- tape
- scratches
- handwriting
- chains / metal hardware
- type fragments

### Portrait hierarchy
- One main portrait is the hero.
- Supporting portrait imagery is optional.
- Do not create a wall of repeated faces.
- The human should read first; collage should read second.

### Good chaos vs bad chaos
Good chaos:
- asymmetry
- torn edges
- uneven red accents
- cropped typography
- controlled overlaps
- clear focal point

Bad chaos:
- five or more repeated portraits
- every corner filled
- random readable phrases
- important facial features obscured unintentionally
- identical decorative marks repeated across a batch

### Typography
Use the user's exact main text.
Small decorative text should normally be abstract or non-readable unless the user supplied it.

### Face preservation
Do not reshape the jaw, nose, lips, eyes, or face proportions just to make the subject “fit” the style.
