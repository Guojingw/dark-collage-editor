# No-Code User Flow

The skill should feel like using a simple photo filter app through conversation.

## Minimal interaction

User uploads one or more photos.

The assistant asks only what is missing:

**How strong should the collage be?**
- Clean
- Editorial
- Chaotic

**What text should appear?**
- User supplies exact wording
- No text

For multiple photos:

**How should the set feel?**
- Consistent series
- More variation

Then edit.

## Defaults

If the user says only “make these dark collage style”, use:
- Editorial
- No text
- Consistent series
- Preserve identity strictly
- 1 supporting portrait fragment at most
- Medium red
- Medium grain
- Strong but controlled contrast
